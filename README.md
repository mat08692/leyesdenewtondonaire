# ¿Por qué nos vamos para adelante cuando frena el colectivo? Fuerzas y leyes de Newton

Recurso Educativo Abierto (REA) para trabajar las fuerzas y las tres leyes de Newton a partir de situaciones de la vida cotidiana.

**Ver el sitio:** https://mat08692.github.io/leyesdenewtondonaire/

## Sobre el recurso

- **Autora:** Lic. Georgina Núñez
- **Área:** Física. Mecánica: fuerzas y leyes de Newton
- **Destinatarios:** estudiantes de nivel secundario (ciclo orientado) y de cursos o talleres de ingreso a estudios superiores
- **Licencia:** [Creative Commons Atribución-CompartirIgual 4.0 Internacional (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/deed.es)

El sitio incluye una animación interactiva sobre la inercia, un diagrama de fuerzas, un laboratorio para explorar la relación F = m · a, una actividad guiada con el simulador de PhET, preguntas con retroalimentación automática y una autoevaluación. Fue diseñado siguiendo los principios del Diseño Universal para el Aprendizaje (DUA): permite agrandar la letra, activar un modo de alto contraste, navegar con el teclado y usar lectores de pantalla.

## Cómo reutilizarlo

1. Descargá el repositorio (botón **Code → Download ZIP**) o hacé un **fork** desde tu cuenta de GitHub.
2. Abrí `index.html` con cualquier editor de texto para modificar los textos, las preguntas (lista `PREGUNTAS`) o el enlace de entrega de actividades (`ENLACE_ENTREGA`).
3. Para usarlo sin conexión, abrí `index.html` en el navegador. Todo funciona, salvo el simulador de PhET, que requiere internet.

En la guía de reutilización encontrás sugerencias de adaptación y criterios de evaluación.
